# TelTest Operations Center — Stage 08.1

این ماژول رابط و API عملیاتی جاب‌های استخراج، انتقال و کتابخانه محتوا را یکپارچه می‌کند.

## استخراج

- دکمه «استخراج جدید» و فرم جمع‌شونده
- مشاهده داشبورد هر جاب با آمار نوع محتوا و تعداد اجرا
- ویرایش تنظیمات منبع، اکانت، نقطه شروع و سقف پیام
- تکرار جاب به‌صورت یک نسخه مستقل
- اجرای مستقیم و نمایش Cursor
- لاگ اختصاصی و فهرست پست‌های هر جاب

## انتقال

- دکمه «انتقال جدید» و انتخاب جاب استخراج مبدا
- انتخاب اکانت، مقصد و روش Copy یا Forward
- مشاهده، ویرایش، تکرار و اجرای مجدد/Resume
- داشبورد آماری وضعیت آیتم‌ها
- وضعیت مجزای `listed`، `transferring`، `transferred`، `failed` و `skipped`
- لاگ اختصاصی و فهرست دقیق پست‌های هر انتقال

## کتابخانه محتوا

- لینک پست اصلی عمومی یا لینک `t.me/c` برای منابع عددی
- دانلود متن به‌صورت فایل TXT
- دانلود و Cache رسانه از تلگرام در اولین درخواست
- استخراج و نمایش هشتگ‌ها در بخش مستقل
- جستجو بر اساس متن، منبع و Message ID

## سازگاری

جاب‌ها و پست‌های قدیمی حذف یا بازنویسی نمی‌شوند. نگاشت‌های Stage 05 حفظ می‌شوند و لاگ‌های قدیمی `job_logs` کنار لاگ‌های جدید نمایش داده می‌شوند.
